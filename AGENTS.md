# Agent instructions

## Implementation work

For code-writing or source-implementation tasks in this project, delegate the implementation to a GPT-6 Luna subagent and act as coordinator. Give Luna a bounded task, clear acceptance criteria, and relevant project context; review its returned changes and verify them in proportion to the change. If GPT-6 Luna cannot be invoked, report the blocker instead of claiming delegation occurred.

Read-only investigation and explanations may be handled locally without delegation. These instructions apply to this project.

## 實作工作

在本專案進行程式撰寫或原始碼實作時，應將實作委派給 GPT-6 Luna 子代理，主代理負責協調。提供明確範圍、驗收條件及相關專案背景；收到變更後應審查，並依變更規模進行適當驗證。若無法呼叫 GPT-6 Luna，應回報阻礙，不得聲稱已完成委派。

唯讀調查與說明可由主代理自行處理，無須委派。本指示適用於本專案。
